# 結帳串接 Google Sheet（Apps Script）

## 運作方式
網站結帳 → POST 訂單到 Apps Script Web App → 伺服器依 `PRICE_LIST` 重新計價、產生訂單編號 → 寫入試算表「訂單」與「訂單明細」 → 寄通知信 → 回傳訂單編號給網站顯示。

## 部署步驟
1. 建立一個新的 Google 試算表，例如「鍋淬訂單」。
2. 選單「擴充功能 → Apps Script」，刪掉預設內容，貼上 `gas/Code.gs` 全部內容並儲存。
3. 視需要修改最上方 `CONFIG`：
   - `NOTIFY_EMAIL`：新訂單通知信要寄給誰（例如店家信箱）。
   - `SEND_CUSTOMER_EMAIL`：顧客有填 Email 時是否寄確認信。
4. 上方函式選單選 `setup` → 執行，依畫面完成 Google 授權。完成後試算表會出現「訂單」「訂單明細」兩個工作表，狀態欄有下拉選單。
5. 右上「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 複製產生的網址（結尾是 `/exec`），貼到 `index.html` 的
   `const ORDER_ENDPOINT='';` 引號中，提交並發布網站。

貼上網址後，結帳按鈕和提示文字會自動從「模擬訂單」換成正式文案。

## 日後維護
- **改價或新增品項**：`index.html` 的 `products` 與 `Code.gs` 的 `PRICE_LIST` 都要改。訂單金額以 `PRICE_LIST` 為準。
- **改了 Code.gs 之後**：要到「部署 → 管理部署作業 → 編輯 → 版本選『新版本』→ 部署」，網址不變；只按儲存不會生效。
- **處理訂單**：在「訂單」工作表把狀態改為 已收到 / 製作中 / 可取餐 / 已完成 / 已取消。狀態一改，同列最右邊的「更新時間」會自動更新（`onEdit`），客人在「訂單查詢」頁按「重新查詢」就會看到。舊資料的「新訂單」「已確認」會顯示為「已收到」。
- **升級既有試算表**：貼上新版 `Code.gs` 後，再執行一次 `setup`（會補上「更新時間」欄與新的狀態下拉選單），然後重新部署新版本。
- **訂單查詢**：`GET <網址>/exec?action=lookup&orderId=…&phone=…`。訂單編號與電話都符合才回傳，且只回傳品項、金額、狀態與時間，不含姓名、電話、地址。
- **寄信額度**：一般 Gmail 帳號每天約 100 封。

## 已內建的保護
- 價格由伺服器計算，前端改價無效。
- 驗證電話、Email、取餐方式、宅配地址、品項與數量。
- 防止試算表公式注入（以 `=`、`+`、`-`、`@` 開頭的文字）。
- 隱藏欄位擋簡單的機器人。
- 鎖定機制避免同時下單時訂單編號重複。
